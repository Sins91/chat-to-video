# 视频工作流连通性测试方案

## 测试边界

- MySQL、Redis、MinIO 和 NestJS API 必须启动。
- 图片上传探测和真实媒体测试还要求独立 Worker 启动。
- `.env.local` 必须配置有效的 `APIMART_API_KEY`。
- 默认 API 地址为 `http://localhost:4101`，可用 `CONNECTIVITY_API_BASE_URL` 覆盖。
- 普通 `pnpm test` 只运行 mock 单测，不执行真实规划、图片分析或媒体生成。
- 脚本从构建后的 `@chat-to-video/contracts` 读取共享 Schema 和管线定义；每个一键命令会先构建 contracts。

## 模式

### 无模型预检

```powershell
pnpm.cmd test:connectivity
```

检查 API health、APIMart 余额、共享管线是否包含 `consistency_reference`，以及实时模型价格。不会创建工作流或调用模型。

### 文本规划

```powershell
$env:CONNECTIVITY_MAX_TOTAL_COST_USD = "0.30"
$env:CONNECTIVITY_PLANNING_CONFIRM = "CALL_TEXT_MODELS"
$env:CONNECTIVITY_REPORT_PROMPTS = "true"
pnpm.cmd test:connectivity:planning
```

`test:connectivity:prepaid` 是兼容别名。脚本根据共享管线定义审批 `proposal`、`script`、`scene_plan` 和 `consistency_reference`，停在 `assets` 规划审批点，并确认 `assetBatch`、`videoJob` 均为空。

启用 `CONNECTIVITY_REPORT_PROMPTS=true` 时，脚本读取编译后的 API 模板注册表，并额外输出初始提示词、命中的 Skill ID，以及 `assets` 规划中的场景序号、素材类型和最终提示词。该报告不改变审批边界；使用前先构建 API。

默认单镜头提示应产生 `consistency_reference=not_required`。如果模型意外要求生成锚点图，脚本会在 Seedream 队列前停止。

### 真实成片

```powershell
$env:CONNECTIVITY_MAX_TOTAL_COST_USD = "1.20"
$env:CONNECTIVITY_PAID_CONFIRM = "GENERATE_PAID_VIDEO"
pnpm.cmd test:connectivity:paid
```

只有 `已观察文本扣费 + max(运行时媒体估价, 实时媒体估价) + $0.05` 不超过总上限时，脚本才批准 `assets` 规划。生成后还会验证素材执行审批、`edit`、`compose`、`job.completed` 和播放地址存在。脚本不打印播放签名 URL。

## 图片输入

准备一张非真人产品或元素图片：

```powershell
$env:CONNECTIVITY_REFERENCE_IMAGE_PATH = "D:\fixtures\product.png"
$env:CONNECTIVITY_REFERENCE_PURPOSE = "product"
$env:CONNECTIVITY_REFERENCE_LABEL = "连通性测试产品"
```

支持 JPEG、PNG、WebP，单张必须非空且不超过 10 MiB。脚本同时检查扩展名、二进制文件魔数和 API/Worker 返回的真实 MIME、大小、宽高。

### 仅上传与探测

```powershell
pnpm.cmd test:connectivity:image:upload
```

执行 `POST /reference-images/uploads`、预签名 PUT、complete 和 `pending_upload → validating → ready` 轮询。该模式不调用模型；对象存储和本地 Sharp 探测不计入 APIMart 模型费用。

### 带图规划

```powershell
$env:CONNECTIVITY_MAX_TOTAL_COST_USD = "0.40"
$env:CONNECTIVITY_PLANNING_CONFIRM = "CALL_TEXT_MODELS"
pnpm.cmd test:connectivity:image:planning
```

除普通规划外还验证：

- `gpt-5-mini` 图片分析产生可用的可见特征和一致性要求；
- 上传声明成为 `user_resolved` 的有效用途和标签；
- 敏感内容被阻止，低置信度不会被脚本自动猜测；
- `consistency_reference.sourceReferenceImageIds` 包含上传图片 ID且估价为 `$0`；
- 参考批次复用 `uploaded-ref-{id}` 和 `storage.validated-reference-image`，不调用 Seedream；
- 批准复用结果后能够进入 `assets` 规划，但不批准媒体生成。

### 带图真实成片

```powershell
$env:CONNECTIVITY_MAX_TOTAL_COST_USD = "2.00"
$env:CONNECTIVITY_PAID_CONFIRM = "GENERATE_PAID_VIDEO"
pnpm.cmd test:connectivity:image:paid
```

默认提示创建两个共享同一产品锚点的镜头。每个视频素材的审核结果必须含有已批准的上传参考绑定；随后生成成片。图片分析若识别出真人或敏感内容，脚本会在媒体审批前停止。

## 费用

脚本每次运行从 APIMart 公共定价接口读取价格，不把下列数字当作永久常量。截至 2026-08-26：

| 模型或档位 | 价格 |
| --- | ---: |
| `gpt-5-mini` 输入 | `$0.20 / 1M tokens` |
| `gpt-5-mini` 输出 | `$1.60 / 1M tokens` |
| Seedance 2.0 480P | `$0.0825/秒` |
| Seedance 2.0 `480P-input` | `$0.05/秒` |
| FlowMusic generate | `$0.075/次` |
| Seedream 5.0 Pro 2K | `$0.073125/张` |

默认无图成片生成 4 秒视频和一条音乐，实时媒体估价为 `$0.405`。当前运行时仍按固定 720P 视频单价保守估价为 `$0.785`。

默认带图成片包含两个镜头；两个短镜头分别向上取整到 4 个生成秒。按 `480P-input` 档推算，媒体估价为 `8 × $0.05 + $0.075 = $0.475`，当前运行时保守估价为 `$1.495`。

图片上传本身成本为 `$0`；图片规划比普通规划多一次 `gpt-5-mini` 多模态分析，结构化修复时最多再调用一次。文本和图片 token 成本以测试前后余额差为准。

当前仓库生成一张锚点图估价为 `$0.0366`，低于实时 Seedream 2K价格 `$0.073125`。因此脚本发现任何需要生成的参考图或低估的图片素材时都会 fail closed。

## SSE、幂等和失败处理

- SSE 连接在规划结束前主动重连一次，使用最大序号发送 `Last-Event-ID`。
- `workflow.snapshot` 和 `heartbeat` 可共享序号；持久事件不得重复回放。
- 每个 `(stage, version)` 只批准一次，重复审批请求不会由脚本自动发送。
- `failed`、`cancelled`、空批次、缺失绑定、缺失播放地址、未知阶段和版本错位均立即失败。
- 超时错误输出 workflow、阶段、版本和批次状态，但隐藏 Token、对象键、预签名地址和播放地址。
- 付费测试失败后不要直接重新运行。先查询打印出的 `workflowId`，确认既有供应商任务和持久化状态，避免重复计费。

## 配置

| 环境变量 | 默认值 | 用途 |
| --- | --- | --- |
| `CONNECTIVITY_API_BASE_URL` | `http://localhost:4101` | NestJS API 地址 |
| `CONNECTIVITY_PROMPT` | 内置 4 秒提示 | 覆盖测试输入 |
| `CONNECTIVITY_REPORT_PROMPTS` | `false` | 在规划模式输出模板 ID 和最终素材提示词；需要已构建的 API 注册表 |
| `CONNECTIVITY_VIDEO_MODEL` | `doubao-seedance-2.0` | 视频模型 |
| `CONNECTIVITY_STAGE_TIMEOUT_MS` | `600000` | 单阶段及图片探测超时 |
| `CONNECTIVITY_PAID_TIMEOUT_MS` | `5400000` | 媒体和成片超时 |
| `CONNECTIVITY_MAX_TOTAL_COST_USD` | 无 | 文本和媒体总费用上限 |
| `CONNECTIVITY_MAX_COST_USD` | 无 | 兼容旧变量，按总费用解释并提示弃用 |
| `CONNECTIVITY_PLANNING_CONFIRM` | 无 | 必须为 `CALL_TEXT_MODELS` |
| `CONNECTIVITY_PAID_CONFIRM` | 无 | 必须为 `GENERATE_PAID_VIDEO` |
| `CONNECTIVITY_REFERENCE_IMAGE_PATH` | 无 | 图片模式的本地绝对路径 |
| `CONNECTIVITY_REFERENCE_PURPOSE` | `product` | character/product/environment/element/style |
| `CONNECTIVITY_REFERENCE_LABEL` | `连通性测试产品` | 上传图片用途标签 |
