# 视频工作流连通性测试方案

## 共同前提

- MySQL、Redis（启用 AOF）、MinIO、NestJS API 已启动。
- 付费测试还要求独立 Worker 已启动。
- `.env.local` 中配置了有效的 `APIMART_API_KEY`。
- 默认 API 地址为 `http://localhost:4101`，可通过 `CONNECTIVITY_API_BASE_URL` 覆盖。
- 两套测试都会调用文本模型生成规划产物，因此都可能产生少量文本模型费用。“付费前”是指不批准图片、视频和音乐等素材生成任务。

## 方案一：素材付费生成前连通性

运行：

```powershell
pnpm.cmd test:connectivity:prepaid
```

脚本会创建独立工作流，依次等待并批准 `proposal`、`script`、`scene_plan`，然后停在 `assets` 规划审批点。通过条件：

- REST 创建、查询和审批接口可用；
- Mastra 能启动、暂停并恢复；
- MySQL 中的阶段和版本持续推进；
- SSE 至少收到 `workflow.snapshot` 和 `cinematic.artifact.completed`；
- 素材规划包含逐项及汇总美元费用；
- `assetBatch` 和 `videoJob` 均为 `null`，证明未进行素材队列交接。

可覆盖输入文本：

```powershell
$env:CONNECTIVITY_PROMPT = "制作一个6秒的单镜头品牌短片……"
pnpm.cmd test:connectivity:prepaid
Remove-Item Env:CONNECTIVITY_PROMPT
```

## 方案二：预算门禁后的真实成片

先运行方案一查看预计素材费用。真实测试需要同时设置费用上限和固定确认令牌：

```powershell
$env:CONNECTIVITY_MAX_COST_USD = "0.50"
$env:CONNECTIVITY_PAID_CONFIRM = "GENERATE_PAID_VIDEO"
$env:CONNECTIVITY_PROMPT = "制作一个6秒的单镜头测试视频……"
pnpm.cmd test:connectivity:paid
Remove-Item Env:CONNECTIVITY_MAX_COST_USD
Remove-Item Env:CONNECTIVITY_PAID_CONFIRM
Remove-Item Env:CONNECTIVITY_PROMPT
```

执行顺序：

1. 完成与方案一相同的全部前置流程；
2. 输出素材规划的逐项费用和汇总费用；
3. 校验汇总费用不高于 `CONNECTIVITY_MAX_COST_USD`；
4. 发送素材规划批准，触发图片、视频和音乐队列；
5. 等待全部素材生成并进入 `awaiting_approval`；
6. 批准实际素材，创建 continuation run；
7. 自动生成剪辑方案并交给 FFmpeg 合成；
8. 等待工作流 `succeeded`、SSE `job.completed` 和最终 `playbackUrl`。

费用门禁只覆盖素材规划中的 `totalEstimatedCostUsd`，不包含文本模型调用、基础设施、网络和失败重试成本。测试账户还应配置独立的供应商余额上限。

## 可选配置

| 环境变量 | 默认值 | 用途 |
| --- | --- | --- |
| `CONNECTIVITY_API_BASE_URL` | `http://localhost:4101` | NestJS API 地址 |
| `CONNECTIVITY_PROMPT` | 内置 6 秒单镜头提示 | 测试输入文本 |
| `CONNECTIVITY_VIDEO_MODEL` | `doubao-seedance-2.0` | 视频模型档位 |
| `CONNECTIVITY_STAGE_TIMEOUT_MS` | `600000` | 单个规划阶段超时 |
| `CONNECTIVITY_PAID_TIMEOUT_MS` | `5400000` | 素材与成片总等待超时 |
| `CONNECTIVITY_MAX_COST_USD` | 无 | 允许的最大预计素材费用 |
| `CONNECTIVITY_PAID_CONFIRM` | 无 | 必须等于 `GENERATE_PAID_VIDEO` |

付费测试失败后不要直接重复运行。先用返回的 `workflowId` 查询持久化快照，确认既有任务状态，避免重复供应商调用。
