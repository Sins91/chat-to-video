# Web 工作区

## 会话切换

- “新对话”立即清空当前会话和 URL 中的会话 ID，不等待服务端页面导航；首条消息发送后才持久化新会话。
- URL 尚未同步时，不按旧会话 ID 恢复内容；重复点击空白页的“新对话”仍可正常发送首条消息。历史会话恢复完成前禁止发送、入队和添加参考图，失败时保留草稿。
- 切换或新建会话会使旧加载、工作流操作和视频回看请求失去更新当前界面的权限；旧请求仍可在后台完成。SSE 和队列轮询只更新所属会话的工作流。
- 参考图草稿按本地聊天会话隔离；切换时释放预览 URL 并放弃未发送的参考图，迟到的上传结果不进入新草稿。已发送或入队的图片交由消息持有，不随输入框卸载而放弃。
- 流式消息完成后通过独立历史请求确认持久化，只移除历史中已出现的消息 ID；加载失败、结果未齐或会话已切换时保留实时消息，重新进入会话后再确认。

## Agent 响应式布局

- 视口宽度小于 `64rem`（默认 1024px）时，预览在上、会话在下；其余宽度保持左会话、右预览。
- 两种布局均可拖动分隔线调整占比，默认会话占 55%、预览占 45%。
- 切换布局复用同一组面板和工作流 Provider，不重建会话组件。
- 窄屏下历史列表收进聊天标题栏的“历史对话”抽屉，切换成功后关闭；被阻止的切换保持抽屉打开。切回宽屏时恢复侧栏并关闭抽屉。
- 输入工具栏按可用宽度换行、模型名称截断，发送按钮始终保留；普通消息中的长文本换行，表格与代码块仅在各自内部横向滚动。
