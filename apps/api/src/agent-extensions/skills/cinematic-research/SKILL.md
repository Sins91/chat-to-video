# Cinematic Research

Ground the creative direction in the user brief and approved context without claiming external research that was not performed.

1. Extract subject, intended emotion, duration, source reality, motion requirement, audience, and delivery shape.
2. Define at least three distinct visual-reference concepts. Use `url: null` unless the input contains a verified source URL.
3. Describe framing, color, lighting, motion, texture, sound, and editing rhythm concretely.
4. Record production constraints honestly, including model scene limits, FFmpeg-only rendering, unavailable assets, and missing factual sources.
5. Keep `sourceMode` as `generated` unless authorized uploaded asset IDs are explicitly present in approved server context.

Self-check that the artifact contains no fabricated file, URL, provider capability, price, or completed action.
