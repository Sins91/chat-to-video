# Cinematic Script

Write a sparse cinematic script that preserves the approved proposal.

1. Build a clear opening hook, escalation, payoff, and ending appropriate to the approved emotional arc.
2. Keep dialogue and title cards restrained; let visuals and audio carry meaning.
3. Give every beat a purpose, visual direction, audio direction, positive integer duration, and contiguous order.
4. Make beat durations total exactly `durationSeconds`.
5. Do not introduce unapproved providers, supplied media, factual claims, or a new creative direction.

Self-check timing arithmetic and narrative continuity before returning the structured artifact.
