# Media Agent Rules

本文件适用于 `packages/media/**`，补充 `packages/AGENTS.md` 与仓库根目录的总体架构原则。

- 本包统一封装媒体参数、探测、预设以及 FFmpeg、FFprobe、Sharp 的安全执行；业务层不得拼接 Shell 命令或直接调用媒体二进制。
- 进程调用使用受控可执行文件路径和参数数组；用户、模型或外部服务文本必须先经白名单 Schema 转换，不能原样成为命令、滤镜、协议或文件路径。
- 对输入大小、时长、分辨率、编码器、输出格式、执行时间和并发数设置上限；媒体参数和导出预设须确定且可复现。
- 每个任务使用独立、受控的临时目录，并为成功、失败、超时和取消提供可靠清理；不得接受未校验的绝对路径或目录穿越片段。
- FFprobe 负责可信媒体元数据探测；Sharp 负责静态图层标准化；FFmpeg 负责转码、滤镜、拼接、混音和导出，避免职责重叠。
- 捕获有界的 `stderr` 与进度信息并脱敏。测试使用小型确定性 fixture，验证元数据、关键帧或哈希等稳定属性，不只断言文件存在。
